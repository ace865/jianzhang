## 自动与构建检查

本地使用独立 Flutter 3.47.6 / Dart 3.13.5、Xcode 27.0 beta（27A5237l）、Ruby 4.0.7、CocoaPods 1.17.0 和 JSON 2.18.0。没有修改系统选中的 Xcode。本地已通过依赖锁文件校验、格式检查、静态检查、82 项测试、UTC／上海／纽约三个时区回归，以及最终 iOS 无签名 release 构建。CI 结果以 PR 对应提交为准。

新增虚构 Android 格式备份样例，验证独立数据库恢复、再导出、整数金额、分类关联、预算、小记、设置和微信去重记录。新增 iOS 平台风格的小屏界面测试，覆盖安全区域、字体放大、键盘和双主题。测试发现记账编辑器的字段行溢出，已限制字段值的宽度，保留右侧对齐和点击操作；该测试复跑通过。这些测试不运行在 iPhone 上，也不证明真实原生插件已验收。

首次 CI 发现 Ruby JSON 库版本不同，空数组格式化不同，导致相同插件的 Pods 校验值不同。已使用 Bundler 锁定 Ruby 工具，并继续使用 `pod install --deployment` 校验，未放宽依赖验证。

GitHub Actions 保留 Android 检查，新增 macOS 作业，记录 Apple 工具链、安装锁定的 Pods、运行共享测试，并构建 iOS 无签名 release。最终结果以 PR 对应提交为准。

最终构建产物核对：名称“简账”、Bundle ID `cn.local.jianzhang`、系统版本 `1.2.0`、构建号 `4`、最低系统版本 `15.0`。未签名产物仅用于构建验证。
