## 已完成的自动验证

- Flutter 3.47.6 / Dart 3.13.5，JDK 21，Android SDK 36；依赖锁文件安装、代码格式和静态检查。
- 78 项测试：账本/主界面 21 项、微信导入 22 项、AI 核心 29 项、AI 界面 6 项。仅虚构账本、模拟 HTTP/SSE 和内存安全存储，不发送真实付费请求。
- Excel 1900／1904 日期系统、午夜和夏令时附近日历字段；GitHub Linux 检查在 UTC、上海、纽约执行，并校验进程实际时区。纽约验证旧算法会将虚构 2026-10-01 23:30 移到次日 00:30，新算法保持原字段。
- 无收入分类时失败收入不阻塞有效支出；有效条目缺分类默认不选；全部分类停用、重复条目和恢复分类后预览；已选分类被停用全部回滚，未选条目不阻塞。界面“选择可导入账单”不会误选缺分类条目。
- 数据库 v1→v2 各旧表保留、现有 v2 重启、旧备份恢复、新备份往返及恢复后去重。模拟来源写入失败整批回滚，拒绝 DB3 降级且保留原记录。
- 导入后整数金额、统计、预算、检索、CSV 导出；AI 快照变化、旧报告保持原快照、界面过期提醒；商户、订单号、备注不出现在 AI 汇总中。
- AI 配置、密钥和加密历史在数据库重启/备份恢复后保留，备份不含 AI 记录或密钥，重启不自动重发请求。协议、取消、超时、证书拒绝及重定向拦截等既有回归保留。
- 双主题、小屏、字体放大、模拟键盘 inset 和流式交互。图片由 Flutter 测试渲染虚构数据，不是真机或真实模型效果。

## 尚未完成的真机验收

没有连接真机，不做模拟器测试。手机安装、覆盖升级、文件选择、原始微信 CSV 和 GB18030 原生解码、系统安全存储、杀进程后的持久化、实际网络/服务商计费与兼容性、帧率/功耗/冷启动尚未验证。自动测试不替代这些结果；iOS 工程未实现。

同应用标识、原签名和更高构建号支持覆盖 1.0、1.1 微信导入开发版和 1.2 AI 独立开发版。迁移与保留已有 v2 的自动回归通过，但不能据此宣称所有手机已验收。先导出 JSON 备份并复制到应用之外，直接覆盖安装，不卸载、不清除数据；安装拒绝时保留旧应用并反馈。测试版先用测试账本，不承诺长期真实数据安全。

本版仍为 beta 预发布，不升级为 rc/正式版。AI 兼容性仅模拟验证，密钥只在应用内填写，不通过 Issue、PR 或聊天提供。服务商可能保留发送数据，删除本机聊天不等于删除服务商副本。
