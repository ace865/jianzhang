# 1.0.0-beta.1 验证记录

日期：2026-10-05。首个安卓测试版，尚未进行手机实测。

## 已完成

- Flutter 静态检查无问题。
- 20 项自动化测试通过：14 项数据库 / 金额 / 备份测试，6 项界面交互和渲染测试。
- 金额整数分、增删改、跨月跨年、闰年、筛选与搜索、分类停用、预算阈值及复制、完整备份往返、损坏备份保护、事务失败回滚、一万条记录分页、CSV 转义、关闭重开持久化、未来日期图表覆盖。
- 空账本启动、主题持久化、四页切换、记账 / 编辑 / 删除、320×640 小屏及 1.3 倍字体、备注键盘、预算及分类对话框、日历小记及未保存草稿保留。
- Android debug 与个人签名 release APK 构建成功。签名校验通过；包名 `cn.local.jianzhang`，版本 `1.0.0-beta.1`，versionCode `1`。
- minSdk 24（Android 7），targetSdk 36；包含 arm64-v8a、armeabi-v7a、x86_64。
- 检查 release 合并清单：未请求网络、通讯录、定位或相册权限；仅包含 AndroidX 的应用内部广播权限。
- A / C 两套界面使用隔离的样例数据库进行 Flutter 渲染检查。样例记录不会进入安装包。
- GitHub 私有仓库：`ace865/jianzhang`。签名材料和账本数据不上传。
