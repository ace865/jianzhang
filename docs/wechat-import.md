## 使用与规则

在设置中选择“导入微信账单”，选择已解压的 CSV 或 .xlsx，预览、修改分类与勾选后确认导入。取消不写入账本。文件在手机本地读取，不增加联网权限，不自动读取微信账户，不支持 ZIP、PDF、加密表格或旧 .xls。

按列名识别表头，支持说明行、UTF-8/GB18030 CSV、Excel 日期数值与文本日期。金额保存为整数分，不接受超出两位小数的金额。上限为 20 MB、20,000 条明细，超限请分段导出。无法可靠恢复的数值型长订单号、公式及坏字段显示异常，不执行公式或外部链接。

| 操作或情况 | 反馈 |
| --- | --- |
| 选择文件 | 后台读取和解析；可取消 |
| 普通成功收支 | 默认选中，显示本地分类建议，可改分类或收支类型 |
| 重复单号 | 跳过，不覆盖旧账；同号内容冲突时阻止入账 |
| 缺少单号、疑似手工重复 | 默认不选，用户明确确认后可导入 |
| 退款、转账、充值、提现及未知状态 | 单独待确认；可作为收入或支出选入，但不会抵扣旧消费 |
| 失败、关闭或撤销交易 | 不入账 |
| 确认导入 | 重新校验分类和重复信息，事务内一次写入 |
| 写入失败 | 全部回滚，提示重新预览 |
| 写入成功 | 显示成功、重复跳过、未选入数量，刷新统计 |

分类仅为本地关键词建议。微信来源记录与账单一起存入数据库 v2；备份 v2 保留去重信息，并兼容恢复旧 v1 备份。恢复旧备份无法找回其中原本没有的导入来源，只能通过疑似重复提示辅助确认。新版备份不能由旧版应用恢复，请使用新版应用。

导入保留商户、商品及原备注作为账单备注，超过现有 500 字限制时截取；支付方式统一标为微信，不建立银行账户。退款等特殊交易若人为选为普通收入/支出，会改变该期间统计，请核对后操作。

原始账单不进入源码、截图或测试夹具。公开测试使用虚构数据。提供的微信 .xlsx 仅用于核对文件结构；CSV 原始导出兼容性、Android 真机文件选择及系统 GB18030 解码仍需实际验收。iOS 工程未实现，不声明两端验收通过。
