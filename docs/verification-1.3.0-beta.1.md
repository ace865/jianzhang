## 安装及未验收项

先将 JSON 备份保存到应用之外。包核对原签名和更高构建号后直接覆盖安装，不卸载、不清除数据；安装失败保留旧应用并反馈。建议先使用测试账本。首次启动仍为空账本，无内置密钥或演示消费。

尚未连接手机或运行模拟器。Android 覆盖升级、系统浏览器跳转、安全存储、重启持久化和性能未测量；没有真实 API 密钥，七家服务商的实际模型查询与聊天兼容性未验证，仅模拟协议。千问普通北京地址不能查询，需要业务空间专属地址；智谱在线刷新暂不支持。目录不保证模型权限或实时可用性。

iOS 15 工程存在且由 macOS 检查，不提供 IPA；iPhone 签名、安装、浏览器、Keychain、升级和性能未验证。正式版与 iOS 渠道须另行双方确认；PR 仍需 songyu 对最新提交批准后才能合并。
