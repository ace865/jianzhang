## 发布说明草稿

Android `1.3.0+8`，最低 Android 7.0，包含 ARM64、ARMv7 和 x86_64。本次仅 GitHub Releases Android 正式版及匹配源码 ZIP，iOS 无安装包，应用商店不在范围内。

包含服务商预设、模型搜索、官方链接与安全手动查询；汇总 AI 配置恢复/密钥异常保护、微信 CSV 换行兼容/退款冲突核对、完整 AI 回复仅重试本地保存与复制、同名分类区分、夏令时日期和账单筛选文案修复。保留离线账本、可选 AI、加密历史和双主题，不内置公共密钥。

数据库与账本备份仍为 v2，不自动改写旧账；包含新导入摘要的备份需本修复版或后续版本恢复，不建议降级。升级前把完整 JSON 备份复制到应用之外，原签名覆盖安装，不卸载或清除数据。

用户报告真我 GT Neo 5 / Android 16 上，`1.3.0-beta.2+7` 安装/覆盖升级、记账编辑删除、统计、备份恢复、文件导入、重启持久化和 AI 设置/模型查询/聊天全部通过。此为用户反馈，非 Codex 独立真机结果；不扩展为所有手机、系统、服务商和旧版本均已验收。正式 build8 仅改版本元数据，仍需补充最终包核对与必要升级验收。自动检查、正式包签名与摘要见[验证记录](verification-1.3.0.md)。

已知限制：模型列表不保证权限或实时可用性；千问刷新需业务空间专属地址，智谱暂不支持在线刷新。没有性能测量数据，不承诺帧率、功耗或冷启动指标。iOS 签名与分发未完成。
