# 1.1.0-beta.1 验证记录

本记录描述微信导入开发分支，不代表已经审阅合并或正式发布。产品版本 `1.1.0-beta.1+2`，Android 工程；iOS 未实现。

## 已完成

- Flutter 格式检查与静态检查通过；39 项自动化测试通过（原有 20 项及新增 19 项）。
- 微信 CSV 表头偏移、列顺序、BOM、引号与换行、文本长单号、UTF-8 解析。
- GB18030 回退调用已用模拟系统接口验证；不是 Android 真机编码验收。
- XLSX Excel 数值日期、1904 日期系统、文本单号、数值长单号保护、公式拒绝、文件及条数上限。
- 重复文件、文件内重复、同号冲突、疑似手工重复、退款确认、提交时重复和分类重验。
- 整批写入失败回滚，数据库 v1→v2 迁移保留所有旧表内容；备份 v2 往返、来源校验、旧 v1 恢复及删除来源清理。
- 2,000 条虚构明细批量入账，金额、按日汇总、搜索分页和 CSV 导出结果一致；不将此结果当作真机性能测量。
- 双主题渲染、320×640 与 1.8 倍字体布局、预览取消无写入，以及确认退款并提交后收入/支出统计。
- 用户提供的微信 .xlsx 在本机只读解析，日期与金额校验通过；原记录没有进入公开夹具、截图或日志。
- Android debug 与保留原密钥的 release 构建成功。签名及实际 versionCode 核对结果附在合并请求交接中。

## 尚未完成
